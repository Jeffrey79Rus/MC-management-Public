# MC 교육 프로그램 카탈로그 · 희망 조사

- `index.html` : 과정 카탈로그
- `survey/` : 교육 희망 조사. 제출하면 Supabase 저장소에 바로 저장됩니다.
- `survey/config.js` : Supabase Project URL과 publishable(anon) 키를 넣는 곳
- `supabase/setup.sql` : Supabase SQL Editor에서 한 번 실행하는 저장소 설정문

응답 표는 직접 읽거나 쓸 수 없고, 정해진 함수로만 접근합니다. 이름별 응답은 관리자 키가 있어야 보입니다.
